# 📊 Sales Dashboard in Microsoft Excel

## 📌 Project Overview

This project demonstrates how to create an interactive and professional **Sales Dashboard** using **Microsoft Excel**.

The project starts with raw sales data containing information about orders, sales persons, customer types, regions, product categories, products, quantities, unit prices, discounts, and revenue. The data is then organised and analysed to create an interactive dashboard that provides a clear overview of sales performance.

The dashboard combines **KPI Cards, Charts, Slicers, and Timeline Filters** to make the analysis interactive and easy to understand. It can be used to monitor revenue, identify top-performing products and categories, compare regional performance, and analyse sales trends over time.

## 📊 Sales Dashboard

The **Sales Dashboard** transforms the raw sales data into an interactive visual report.

It contains KPI cards that display **Total Revenue, Total Orders, Quantity Sold, and Average Order Value**. It also includes different charts to analyse revenue by month, product category, top products, and region.

The dashboard also uses interactive **Slicers** and **Timeline Filters**, allowing users to filter the report by Sales Person, Customer Type, Region, Category, Year, Quarter, Month, and Day.

### Features

* 💰 **Total Revenue** – Shows the overall revenue generated from sales.
* 🛒 **Total Orders** – Displays the total number of orders.
* 📦 **Quantity Sold** – Shows the total number of products sold.
* 💳 **Average Order Value** – Displays the average value of orders.
* 📈 **Revenue by Month** – Shows monthly revenue trends.
* 📊 **Revenue by Product Category** – Compares revenue across categories.
* 🍩 **Top 5 Products by Revenue** – Highlights the highest-revenue products.
* 🌍 **Revenue by Region** – Compares sales performance across regions.
* 🎛️ **Interactive Slicers** – Allows users to filter the dashboard dynamically.
* 📅 **Timeline Filters** – Allows users to analyse sales by year, quarter, month, and day.

## 🔍 Key Insights

The dashboard provides several important sales insights:

* 💰 **Total Revenue:** $1.67M
* 📦 **Quantity Sold:** 4,850 units
* 🏆 **Electronics** generated the highest revenue among the product categories.
* 🌍 **North** was the highest-performing region.
* 📱 **Smartphone** generated the highest revenue among the individual products.
* 📈 Monthly revenue changes throughout the year, allowing high- and low-performing periods to be identified.
* 🎯 The interactive filters make it easier to analyse specific sales persons, customer types, regions, and product categories.
